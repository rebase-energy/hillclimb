                                                                                                                        
 Usage: root connect codex [OPTIONS]                                                                                    
                                                                                                                        
 The Codex CLI as the operator agent.                                                                                   
                                                                                                                        
 Runs `codex login`, then copies the credential into the isolated                                                       
 `CODEX_HOME` searches use, so your personal `~/.codex` settings change                                                 
 neither a search's results nor its token bill. `--auth openrouter` bills                                               
 OpenRouter credits instead (`hillclimb connect openrouter` first).                                                     
                                                                                                                        
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────────────────────────╮
│ --auth                         TEXT  Who pays: subscription (default) | api-key | openrouter                         │
│ --model                        TEXT  Model to ping with (default: the configured one)                                │
│ --probe        --no-probe            Make one tool-free agent call to prove the route works [default: probe]         │
│ --login        --no-login            Run `codex login` when logged out [default: login]                              │
│ --default      --no-default          Pin this agent as the default. Default: only when none is pinned there yet      │
│ --local        --user                Where the defaults (and an OpenRouter key) go: --user (the default) is          │
│                                      ~/.config/hillclimb/, every folder on this machine; --local is this folder's    │
│                                      hillclimb dir, overriding the user level for it alone                           │
│                                      [default: user]                                                                 │

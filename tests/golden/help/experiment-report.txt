                                                                                                                        
 Usage: root experiment report [OPTIONS] [STUDY]                                                                        
                                                                                                                        
 Compare the experiments of a study.                                                                                    
                                                                                                                        
 On the selected candidate's holdout score (val when holdout was off):                                                  
 per experiment n/mean/median/spread, best-of-repeat wins, time to best                                                 
 and tokens; then every experiment against the control, with the gap                                                    
 judged against the noise floor (`hillclimb verify <problem> --repeat 5` measures it).                                  
                                                                                                                        
╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────────────────────────╮
│   [study]      TEXT  Study name or spec (default: every study)                                                       │
╰──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────────────────────────╮
│ --problem              TEXT   Filter to one problem id                                                               │
│ --control              TEXT   Experiment to compare against (default: the first)                                     │
│ --noise-floor          FLOAT  Gap below which experiments are not different (default: the spec's)                    │
│ --json                        Machine-readable: the summaries as JSON (a meta-verifier reads the gaps)               │
│ --help         -h             Show this message and exit.                                                            │
╰──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────╯

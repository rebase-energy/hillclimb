                                                                                                                        
 Usage: root run [OPTIONS] TARGET                                                                                       
                                                                                                                        
 Start a run on a problem or a run-spec YAML.                                                                           
                                                                                                                        
 The search runs in the background and the terminal comes straight                                                      
 back: `hillclimb watch` follows it, `hillclimb stop --all` ends it.                                                    
 `--no-detach` keeps it in this terminal instead (Ctrl-C stops it).

│ *    target      TEXT  [required]                                                                                    │
╰──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────────────────────────╮
│ --budget                                                   TEXT                  Wall-clock budget, e.g. 2h / 30m    │
│ --agent,--backend                                          TEXT                  The coding agent that runs the      │
│                                                                                  operators: claude-code | codex | pi │
│                                                                                  | dummy | toy (the last two need no │
│                                                                                  LLM; --backend is the old spelling) │
│ --model                                                    TEXT                  Model the coding agent runs, e.g.   │
│                                                                                  sonnet / opus                       │
│ --climber                                                  TEXT                  The climber: a .py file, a climber  │
│                                                                                  folder, or package.module:Class     │
│                                                                                  (hillclimb climber list shows the   │
│                                                                                  catalog's). It replaces the         │
│                                                                                  `climber:` block of hillclimb.yaml  │
│                                                                                  (or of the run spec); --set         │
│                                                                                  climber.params.k=v edits it. Repeat │
│                                                                                  it (--climber climbers/greedy       │
│                                                                                  --climber climbers/gepa) for a      │
│                                                                                  mixed fleet: one search per climber │

│ --parallel-agents,--parallel-operat…                       INTEGER               Concurrent coding agents per        │

│                                                                                  (--parallel-operators is the old    │
│                                                                                  spelling)                           │

│                                                                                  (time, throughput, memory)          │
│ --seed-from                                                PATH                  Incumbent solution.py scored as the │

│ --set                                                      TEXT                  Any config setting, dotted: --set   │

│                                                                                  learning.enabled=false              │
